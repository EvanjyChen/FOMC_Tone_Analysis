# FOMC Hawkish-Dovish Tone Project

Course: CS 5100

This project converts public Federal Open Market Committee minutes into a
reproducible hawkish-dovish policy stance index. It compares a transparent
dictionary baseline with weakly supervised FinBERT, evaluates both against an
independent 30-sentence human audit, aggregates document-level tone, and
examines exploratory associations with Treasury yields.

## Project Structure

- `scripts/fetch_data.py`: downloads public FOMC minutes and FRED Treasury yield
  data.
- `scripts/analyze_tone.py`: sentence splitting, dictionary scoring,
  aggregation, market-association analysis, and figure generation.
- `scripts/finbert_optional.py`: optional FinBERT fine-tuning and prediction
  workflow for the advanced model section.
- `scripts/evaluate_classifier.py`: independent human-audit evaluation, metrics,
  examples, and confusion matrices.
- `scripts/make_report.py`: generates the final PDF report from computed
  results.
- `scripts/make_slides.py`: generates presentation slides as a PDF.
- `data/raw/`: downloaded raw text/market data.
- `data/processed/`: processed scores and evaluation tables.
- `figures/`: charts used in the report and slides.
- `reports/`: final report PDF.
- `slides/`: presentation slide deck PDF and video script.

## Data Sources

- FOMC minutes:
  [Board of Governors meeting calendars and historical materials](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm).
- Market data: FRED [DGS10](https://fred.stlouisfed.org/series/DGS10) and
  [DGS2](https://fred.stlouisfed.org/series/DGS2) Treasury Constant Maturity
  Rates.
- Base model: [`ProsusAI/finbert`](https://huggingface.co/ProsusAI/finbert).

The raw text files are downloaded from official public pages, and the source
URLs are preserved in `data/processed/fomc_metadata.csv`.

Treasury yields are aligned to FOMC meeting dates using the latest observation
on or before each meeting date. The corresponding minutes are released later.
This is not a minutes-release event study; it describes associations between
meeting-related policy tone and the yield environment around FOMC meeting dates.

## Methods

The main reproducible model is a dictionary baseline. Each FOMC minute is split
into sentences. A sentence is labeled hawkish if hawkish monetary-policy terms
outnumber dovish terms, dovish if the opposite is true, and neutral otherwise.
The document score is:

```text
net hawkish score = (hawkish sentence count - dovish sentence count) / total sentence count
```

The comparison model fine-tunes FinBERT (`ProsusAI/finbert`) as a
hawkish/dovish/neutral sentence classifier. The completed project uses a
balanced weak-supervision training set generated by the dictionary classifier:

```bash
python3 scripts/finbert_optional.py --epochs 2 --batch-size 8
```

The script saves the fine-tuned model under `models/finbert_policy_tone/`,
exports teacher-label agreement metrics, writes
`data/processed/finbert_sentence_predictions.csv`, and aggregates
`data/processed/finbert_document_scores.csv`. Teacher-label agreement is not
independent accuracy. The blind 30-sentence human audit evaluates both
classifiers: the dictionary baseline achieved 53.3% accuracy and 0.531 macro-F1,
while weakly supervised FinBERT achieved 50.0% accuracy and 0.479 macro-F1.
